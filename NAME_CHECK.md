# Name check: quantseal

Coined for this project: **quant** (quantization) + **seal** (a stamp
applied only after verification - the ledger's MEASURED stamp is a seal,
and an unmeasured file gets no seal). The name describes the act the tool
performs: it seals a measurement to the exact file it was measured on.

Checked 2026-11-20:

| Surface | Query | Result |
|---|---|---|
| GitHub repositories | repo-name search for `quantseal` | 0 repositories |
| PyPI | `pypi.org/pypi/quantseal/json` | 404 - no such package |
| Web / products | `"quantseal" software product company` | No product, company or project named QuantSeal surfaced. Results concerned unrelated names (Seal Security, Q-Seal, QuerySeal/qseal, SEALSQ) - none is "QuantSeal" and none works on inference-file measurement. |

Near names considered and rejected:

- `quantproof` - taken: 6 GitHub repositories and a live PyPI package.
- `quantwitness` - taken: a live PyPI package.
- `proofquant`, `verdiquant`, `weightseal` - clean on GitHub/PyPI at check
  time but weaker names (proofquant inverts the metaphor; weightseal reads
  as a hardware product). Held as fallbacks only.

Conclusion: `quantseal` is original to this project on every surface
checked. Any future collision should be recorded here with its date.
